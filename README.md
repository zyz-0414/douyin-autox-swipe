# 抖音自动刷视频（手机 AutoX.js 版）

在手机上直接运行的自动刷视频工具。  
**不需要电脑，不需要 ADB。**

你先手动打开抖音并进入可上下滑的视频页，然后点悬浮窗“开始”。  
脚本会在每条视频随机停留 10–20 秒，再自动上滑到下一条。

## 功能

- 悬浮窗开始 / 停止
- 随机停留 10–20 秒
- 自动上滑翻页
- 显示状态、已刷条数、倒计时
- 连续滑动失败 3 次后自动停止并提示

## 不包含

- 自动打开抖音 / 自动找推荐页
- 点赞、评论、收藏
- 内容识别
- 本地日志
- 电脑端 ADB 控制

## 一、安装 AutoX.js（必做）

本项目依赖手机上的 **AutoX.js（Autox）** 运行。

### 1. 下载安装包

推荐从官方 GitHub Releases 下载：

- 发布页：https://github.com/aiselp/AutoX/releases
- 当前可用版本示例：https://github.com/aiselp/AutoX/releases/tag/v7.2.3

大多数常见安卓手机选这个：

- `Autox-v7-arm64-v8a-release-v7.2.3.apk`

下载地址示例：

- https://github.com/aiselp/AutoX/releases/download/v7.2.3/Autox-v7-arm64-v8a-release-v7.2.3.apk

说明：

- 普通手机优先选带 `arm64-v8a` 的完整版 APK
- `mini` 版功能更精简，一般不优先选
- 如果你的手机浏览器打不开 GitHub，可先用电脑下载 APK，再传到手机安装

### 2. 安装到手机

1. 把 APK 发到手机（微信文件传输助手、数据线、网盘均可）
2. 用手机文件管理器打开该 APK
3. 若系统提示“不允许安装未知应用”，先允许当前应用安装
4. 安装完成后打开 **Autox / AutoX.js**

### 3. 开启必要权限

打开 AutoX.js 后，按提示开启：

1. **无障碍服务**（必须）
   - 进入系统设置 -> 无障碍 / 已下载的应用
   - 找到 AutoX.js / Autox
   - 打开开关并确认
2. **悬浮窗权限**（必须）
   - 允许 AutoX.js 显示在其他应用上层
3. 如系统还有这些选项，建议一并允许：
   - 后台运行
   - 忽略电池优化
   - 通知权限（方便看到脚本状态）

没开无障碍时，脚本不会开始刷视频，只会提示你去开启。

## 二、导入本项目

把整个项目文件夹拷到手机，例如：

```text
抖音自动刷视频-手机版/
  main.js
  project.json
  README.md
  core/
  ui/
```

然后在 AutoX.js 中导入：

1. 打开 AutoX.js
2. 选择“打开”或“导入”
3. 选中本项目文件夹（推荐导入整个文件夹）
4. 确认能看到 `main.js`

如果只能单个导入文件，请至少保证这些文件都在：

- `main.js`
- `project.json`
- `core/config.js`
- `core/gesture.js`
- `core/swipe_runner.js`
- `ui/float_control.js`

## 三、使用步骤

1. 打开抖音，进入可以上下滑的视频页
2. 回到 AutoX.js，运行本项目的 `main.js`
3. 屏幕出现悬浮窗后，点 **开始**
4. 需要结束时点 **停止**

## 悬浮窗说明

- 状态：未开始 / 观看中 / 滑动中 / 已停止 / 失败提示
- 已刷：成功上滑的次数
- 倒计时：当前这条视频剩余停留时间
- 右上角 **关闭**：停止任务并退出脚本

按住上方标题栏，即可拖动悬浮窗。

## 常见问题

### 1）找不到 AutoX.js / 安装后打不开

- 确认安装的是 `Autox-v7-arm64-v8a-...apk`
- 部分手机需要在“应用管理”里允许自启动
- 如果应用名显示为 Autox，也可以，这就是 AutoX.js 运行器

### 2）点开始没反应

请确认 AutoX.js 的无障碍权限已开启。  
可在系统设置里关闭后再重新打开一次无障碍开关。

### 3）一直提示滑动失败

请回到抖音可上下滑的视频页，再点开始。  
若仍失败，检查是否被系统弹窗、权限弹窗或广告遮挡。

### 4）会不会自动打开抖音？

不会。当前版本要求你先手动进入视频页。

### 5）和电脑版是什么关系？

这是独立项目，不依赖电脑版代码，可单独推送到 GitHub。

## 参数

可在 `core/config.js` 修改：

- `minStay` / `maxStay`：停留秒数范围，默认 10–20
- `maxSwipeFailures`：连续滑动失败多少次后停止，默认 3
