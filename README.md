# 抖音自动刷视频（手机 AutoX.js 版）

在手机上直接运行的自动刷视频工具。  
**不需要电脑，不需要 ADB。**

你先手动打开抖音并进入可上下滑的视频页，然后点悬浮窗“开始”。  
脚本会在每条视频随机停留 10–20 秒，再自动上滑到下一条。

## 功能

- 悬浮窗开始 / 停止
- 随机停留 10–20 秒
- 自动上滑翻页
- 显示状态、已刷条数、倒计时
- 连续滑动失败 3 次后自动停止并提示

## 不包含

- 自动打开抖音 / 自动找推荐页
- 点赞、评论、收藏
- 内容识别
- 本地日志
- 电脑端 ADB 控制

## 安装准备

1. 在手机安装 **AutoX.js**（或兼容的 Auto.js）
2. 打开 AutoX.js，开启：
   - 无障碍服务
   - 悬浮窗权限（如系统要求）
3. 把本项目导入 AutoX.js（整个文件夹导入，或至少导入 `main.js` 与 `core/`、`ui/`）

## 使用步骤

1. 打开抖音，进入可以上下滑的视频页
2. 在 AutoX.js 中运行本项目的 `main.js`
3. 屏幕出现悬浮窗后，点 **开始**
4. 需要结束时点 **停止**

## 悬浮窗说明

- 状态：未开始 / 观看中 / 滑动中 / 已停止 / 失败提示
- 已刷：成功上滑的次数
- 倒计时：当前这条视频剩余停留时间

拖动标题文字可移动悬浮窗位置。

## 常见问题

### 点开始没反应
请确认 AutoX.js 的无障碍权限已开启。

### 一直提示滑动失败
请回到抖音可上下滑的视频页，再点开始。  
若仍失败，可稍等 1 秒后重试，或检查是否被系统弹窗遮挡。

### 会不会自动打开抖音？
不会。当前版本要求你先手动进入视频页。

### 和电脑版是什么关系？
这是独立项目，不依赖电脑版代码，可单独推送到 GitHub。

## 参数

可在 `core/config.js` 修改：

- `minStay` / `maxStay`：停留秒数范围，默认 10–20
- `maxSwipeFailures`：连续滑动失败多少次后停止，默认 3
